# Looply 🔄

Looply is an Android app for saving videos on your device and watching them offline.

## Features

- Receive video files and links through Android's Share menu.
- Save selected videos in app-private storage.
- Browse and play saved videos offline.
- Video playback powered by AndroidX Media3 (ExoPlayer).

> Note: Instagram link downloading depends on the external service and Instagram's behavior. Availability is not guaranteed.

## Tech Stack

- **Language:** Kotlin
- **UI:** Android Views and Material Components
- **Playback:** AndroidX Media3 (ExoPlayer)
- **Local database:** SQLite
- **Storage:** App-private internal storage

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ArjunaAyush/Looply.git
   cd Looply
   ```
2. Open the project in Android Studio and allow Gradle sync to finish.
3. Run the app on a compatible Android device or emulator.

## Compatibility

- **Minimum Android version:** Android 12 (API 31)
