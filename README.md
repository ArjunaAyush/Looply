# Looply 🔄

**Looply** is a modern Android application built with Jetpack Compose that lets you save, organize, and loop your favorite Instagram Reels and videos offline.

## ✨ Features

- **Seamless Background Reel Downloader**: Share any reel or video link directly from Instagram to Looply; it downloads in the background without interrupting your flow.
- **Offline Video Looping**: Watch and loop your saved reels anytime without an active internet connection.
- **Modern Jetpack Compose UI**: Clean, responsive interface featuring Material 3 theming with dark mode support.
- **Local Storage & Privacy**: Media and metadata are stored directly on your device using Android Room Database and app-private storage.
- **Smooth Playback**: Powered by AndroidX Media3 / ExoPlayer for high-performance looping and video playback.

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose & Material 3
- **Media Engine**: AndroidX Media3 (ExoPlayer)
- **Database**: Room Persistence Library
- **Networking**: OkHttp
- **Architecture**: MVVM with Kotlin Coroutines & Flow

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ArjunaAyush/Looply.git
   cd Looply
   ```

2. **Open in Android Studio**:
   - Open Android Studio (Ladybug or newer recommended).
   - Select **Open** and choose the `Looply` directory.
   - Let Gradle sync dependencies.

3. **Build & Run**:
   - Connect an Android device (Android 8.0+ / API 26+) or launch an emulator.
   - Click **Run** (`Shift + F10`).
